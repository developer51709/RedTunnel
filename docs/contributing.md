# Contributing to RedTunnel

Thank you for your interest in contributing to RedTunnel!

## Guidelines
- Keep code modular and readable.
- Follow the project's safety principles.
- Document new features clearly.
- Write tests for new modules.
- Avoid adding any functionality that could generate illegal traffic.

## How to Contribute
1. Fork the repository.
2. Create a feature branch.
3. Commit your changes with clear messages.
4. Submit a pull request.

All contributions are reviewed for safety, clarity, and alignment with RedTunnel’s mission.
